## 2.2.2
- Settings, Updates: the update notice is there too (Download, and the install button once it is downloaded), not only at the top of the Inbox. Looking now offers a version you had set aside.

## 2.2.1
- Updates: the permission to install apps from Cemail is asked before the download starts, so the app is not restarted halfway through it.
- Outlook: when Microsoft answers with a server error (500, 502, 503, 504 or 429), reads and changes (read, star, move, delete) wait and try again up to three times instead of being lost.

## 2.2.0
- Unread emails stand out: in the list, an unread message is a lighter tile with a shadow that rises above the card, in every look and in light and dark.

## 2.1.0
- Settings, Updates: what is new in this version, what the next one brings (when there is one) and the earlier versions.

## 2.0.2
- More robust syncing: a network failure while renewing the access permission no longer counts as "signed out" (it only does when Google or Microsoft reject the saved sign-in). Gmail tries IPv4 first, like Outlook, and retries once if the connection never started; Outlook also retries once on a DNS failure.

## 2.0.1
- Update notice: after downloading, an "Install" button reopens Android's installer if it was cancelled.

## 2.0.0
- Load more: a button at the end of each list fetches the next 50 emails that are not on the phone yet. Works with Gmail, Outlook and IMAP.
- Search the server: below the search results, search the whole mailbox at any date.
- Settings, Notifications and sync, Synced emails: Normal, 250 or 500 per account.
- Updates: every version is also published on GitHub; Cemail offers newer ones at the top of the Inbox, and Android asks before installing.
- In an email's More menu, long-press a button to see its name.
- Previews that showed HTML code now show the text.

## 1.10.1
